# Credit Agreement Candidate Set — 2026-09-27

This directory contains 100 vetted, English-language credit-agreement candidates downloaded from SEC filings. It is a review area, not part of the preserved corpus.

- `documents/`: original downloaded files (68 HTM, 31 TXT, 1 PDF)
- `manifest.tsv`: provenance, hashes, validation status, vintage, private-credit role, and leveraged-loan screening labels
- `../../docs/corpus_audit_2026-09-27.md`: audit findings and selection methodology

The set contains 90 broad SEC agreements from 87 distinct registrant CIKs, eight agreements selected for the named private-credit managers, and two older European/cross-border examples. It is sized so that approval and import would move the project from 52 distinct existing agreements to approximately 152.

Do not move these files into `raw_documents/` without explicit approval. Preserve the downloaded bytes and use the manifest when assigning final corpus identifiers.
